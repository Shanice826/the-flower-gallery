# the-flower-gallery
This is a large portfolio piece of creating a multi-page website hosting flower images and facts using vanilla HTML, CSS and JS. In addition, I have used Bootstrap on each page discussing the flowers and the About Me page. The only vanilla JS I used is for making the clock on the homepage. I've learned a lot from creating this website and had a lot of fun in making it.

Enjoy!
